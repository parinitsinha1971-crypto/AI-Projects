# AI Number Predictor

My first machine learning project.

## Overview

This project uses Linear Regression from scikit-learn to learn the relationship between input numbers and their corresponding outputs.

The model is trained using example data and then used to predict outputs for new numbers.

## Example

Training data:

| Input | Output |
|------:|-------:|
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |
| 5 | 11 |

The model learns the relationship:

y = 2x + 1

However, the equation is not directly provided to the model. It learns the relationship from the training data.
